Telegram Bot Дрон

Telegram-бот для прохождения викторины о беспилотных летательных аппаратах (дронах).
Бот задаёт 50 вопросов, проверяет ответы, считает результат и сохраняет статистику пользователя.

Проект написан на Python с использованием aiogram 3.x и развёрнут на Railway.


ВОЗМОЖНОСТИ

- Регистрация пользователя по ФИО
- Викторина из 50 вопросов о дронах
- 3 варианта ответа на каждый вопрос
- Мгновенная проверка ответов
- Подсчёт очков и процента правильных ответов
- Сохранение лучшего результата
- Просмотр профиля пользователя
- Неограниченное количество попыток


КОМАНДЫ БОТА

/start   – регистрация и ввод ФИО  
/quiz    – начать викторину  
/profile – посмотреть профиль  
/help    – список команд  
/cancel  – отменить текущее действие

УСТАНОВКА И ЗАПУСК ЛОКАЛЬНО

1. Клонировать репозиторий:

   git clone https://github.com/likhaalex/dron_bot.git
   cd dron_bot

2. Установить зависимости:

   pip install -r requirements.txt

3. Создать Telegram-бота через @BotFather
   и установить переменную окружения TOKEN

   Linux / macOS:
   export TOKEN=ВАШ_TELEGRAM_BOT_TOKEN

   Windows (PowerShell):
   setx TOKEN "ВАШ_TELEGRAM_BOT_TOKEN"

4. Запустить бота:

   python main.py


ДЕПЛОЙ НА RAILWAY

Проект полностью готов к деплою на Railway.

Что используется:
- runtime.txt — Python 3.11
- requirements.txt — зависимости
- TOKEN — переменная окружения

Шаги:
1. Создать новый проект на https://railway.app
2. Подключить GitHub-репозиторий
3. Добавить переменную окружения:
   TOKEN=ВАШ_TELEGRAM_BOT_TOKEN
4. Railway автоматически соберёт и запустит бота


ЛОГИКА ВИКТОРИНЫ

- Всего 50 вопросов
- Каждый вопрос содержит 3 варианта ответа
- Ответ проверяется сразу
- В конце выводится:
  • количество правильных ответов
  • процент правильных ответов
  • итоговая оценка
- Лучший результат сохраняется в профиле
